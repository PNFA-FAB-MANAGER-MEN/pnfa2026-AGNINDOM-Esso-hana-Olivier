## Appris

- Un dépôt d'équipe se rejoint par invitation par mail, sans avoir à le créer soi-même forcement.
- Une erreur de synchronisation Git peut venir d'une configuration système incomplète : le problème a été résolu en définissant explicitement `user.email` et `user.name` avec `git config --global`.
- La distinction entre FabLab, makerspace et atelier repose sur le respect d'une charte commune (Fab Charter) et l'appartenance à un réseau mondial issu du MIT, alors qu'un simple atelier ou makerspace n'y est pas nécessairement soumis.
- Le premier FabLab togolais, le WoeLab, a ouvert en 2012.

## Raté, puis corrigé

- Échec de la synchronisation du dossier local vers le dépôt distant → hypothèse de cause : configuration Git manquante sur le poste (identité non définie) → correction tentée : exécution de `git config --global user.email ...` et `git config --global user.name ...` → résultat : synchronisation et commit réussis.

## Décidé

- Décision de standardiser la configuration Git (`user.email` / `user.name`) sur tous les postes de l'équipe avant toute nouvelle tentative de commit, afin d'éviter que chacun ne débogue le même problème séparément → motif : gagner du temps collectif, éviter des commits mal attribués.
- Décision de garder VSCode comme éditeur unique de l'équipe, pour que tout le monde voie les mêmes messages d'erreur Git → motif : uniformiser le support pendant l'apprentissage.
